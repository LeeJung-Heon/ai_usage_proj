# Agent Meter v0.1

macOS 14 이상에서 실행되는 SwiftUI 네이티브 앱. Claude Code, Codex, Gemini CLI의 이 Mac에 저장된 사용 기록을 집계하고 Antigravity의 구독 한도를 표시한다.

- 메뉴 막대 요약과 한국어 대시보드, 오늘/7일/30일 필터, 일별 차트, 모델별 사용량.
- 입력/출력/캐시 토큰을 구분하고 중복 응답 및 누적 스냅샷을 중복 합산하지 않는다.
- Claude 계정 한도와 Codex 계정 한도(기존 CLI 로그인)를 직접 조회하고, 실패 시 각각 statusLine의 마지막 기록과 Codex 로컬 로그의 마지막 한도를 표시한다. 오래된 값과 만료된 윈도우는 명확히 표시한다.
- Claude statusLine 수집기는 숫자 한도와 수집 시각만 로컬 저장한다. 앱에서 연결을 선택하면 기존 설정을 백업하고, 기존 statusLine이 있으면 덮어쓰지 않는다.
- Antigravity 실행 중인 앱의 로컬 서버를 자동 탐색해 모델 그룹별 한도와 리셋 시각을 표시한다. 구버전은 모델별 한도로 대체하며 토큰·세션 집계는 미지원이다. 네 에이전트 순서를 보존하고 Antigravity의 메뉴 막대에는 가장 많이 사용한 그룹을 표시한다.
- Gemini JSON/JSONL 세션을 지원한다. 확인할 수 없는 구독 한도는 미지원으로 표시한다.
- 60초 자동 갱신과 수동 갱신. 기본 경로를 자동 탐색하고 설정에서 폴더를 변경할 수 있다.
- 확인 가능한 각 구독 한도가 90% 이상이면 macOS 알림을 보낸다. 최신 기록만 검사하고 한도 기간별 중복 방지 이력을 재시작 후에도 유지한다. 설정에서 알림을 끄거나 권한을 요청할 수 있다. Gemini 한도 알림은 한도 수집 미지원으로 제공하지 않는다.
- 대화 내용은 외부로 전송하지 않는다. Antigravity 한도는 로컬 서버에만 요청하며 인증 정보·원본 응답을 저장하지 않는다. Claude 한도 조회에는 기존 키체인 액세스 토큰을 Claude 서버에, Codex 한도 조회에는 기존 auth.json 액세스 토큰을 ChatGPT 서버에만 전송하며 별도로 저장하지 않는다. 외부 패키지 의존성 없음.
- 실행 가능한 .app, 재현 가능한 빌드 스크립트, 파서/집계/파일 수집 테스트, 한국어 README 제공.

기록 보존 기간과 다른 기기/웹 사용 때문에 로컬 토큰 합계는 계정 전체 사용량과 다를 수 있다. 토큰을 구독 한도나 실제 청구액으로 환산하지 않는다.
